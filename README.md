🚚 AI-Powered Logistics & Shipment Management System

An intelligent logistics management platform that combines **Artificial Intelligence, Machine Learning, predictive analytics, and interactive dashboards** to support smarter shipment and logistics operations.

📌 Overview

The AI Logistics Management System analyzes shipment data and provides intelligent insights for **ETA prediction, delay-risk analysis, shipment prioritization, route intelligence, vehicle analysis, and operational monitoring**.

The project is developed using Python and deployed through a professional Streamlit dashboard.

✨ Key Features

- 🤖 AI-Based ETA Prediction
- ⚠️ Shipment Delay Risk Analysis
- 🚨 Intelligent Shipment Priority Engine
- 📍 Route & Distance Intelligence
- 🚛 Vehicle Intelligence & Allocation
- 🔎 Shipment Tracking
- 📊 Logistics Control Tower
- 📈 Analytics & KPI Dashboard
- 💬 AI Logistics Console
- 🌙 Light & Dark Mode
- 🌐 Interactive Streamlit Dashboard

🛠️ Technology Stack

- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Random Forest**
- **Streamlit**
- **Plotly**
- **Machine Learning**

📂 Dataset

The project uses an **Amazon Delivery Dataset** for shipment analysis, feature engineering, predictive modeling, and logistics intelligence.

🧠 Machine Learning

The system uses a Machine Learning pipeline for predicting delivery time based on available shipment attributes such as:

- Agent information
- Location coordinates
- Weather
- Traffic
- Vehicle
- Area
- Product category
- Order timing

The predicted delivery information is further used to generate operational risk and priority insights.
